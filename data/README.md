# Data layout

Place the official CIC IoT-DIAD 2024 download in:

```text
data/raw/CIC-IoT-IDAD-Dataset-2024/
```

The `data/raw/` directory is excluded from version control. Compact audit outputs are written to
`artifacts/data_audit/`, retained with the code release, and can be regenerated from the raw files
and `config/audit.toml`.
