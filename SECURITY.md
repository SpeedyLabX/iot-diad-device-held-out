# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities through a public issue. Report them privately to
the SpeedyLabX organization maintainers through GitHub's private vulnerability reporting feature.

Include the affected component, reproduction steps, potential impact, and any suggested
mitigation. Avoid attaching raw network traffic, credentials, or non-public dataset material.

## Scope

Security reports may cover the Python package, dataset downloader, artifact verification logic,
or repository automation. Statistical disagreements and research-method questions should use the
regular issue tracker once it is enabled.
